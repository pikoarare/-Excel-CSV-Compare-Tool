## 主な機能

- キー列による比較  
- 行順の違いを無視

- サンプル付き

- ## Overview

This tool allows you to compare two Excel or CSV files and extract differences.

- Added rows
- Removed rows
- Changed values

ExcelやCSVファイルを比較し、差分（追加・削除・変更）を抽出できるツールです。

## How to Use

1. Select File A and File B  
2. Choose a key column  
3. Run comparison  
4. Output files will be generated  

## 使い方

1. ファイルA・Bを選択  
2. キー列を選択  
3. 比較を実行  
4. 差分ファイルが出力されます
